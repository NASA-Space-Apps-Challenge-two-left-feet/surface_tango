The government-hosted layer permits public queries for Armenia municipality code
`63001`. Polygon metadata, a count request, a nonpersonal attribute query, and one
GeoJSON geometry sample were checked. Native CRS is EPSG:9377; the sample requested
EPSG:4326. Reproducible measured record counts and duplicate-name findings are in
the report; none is a count of eligible evaluation units.

Government hosting is verified. **Municipal adoption and event-date validity are
not verified.** The host is a test service; description and copyright fields are
empty. Resolve provenance, reuse terms, stable unit IDs, duplicates, and full
geometry validity before using it for a scientific result. The municipal SIG
catalog offers a recovery path but currently returns access/subscription errors.
