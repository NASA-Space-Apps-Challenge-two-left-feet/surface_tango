ASF's opened release history documents public sample products on January 23, 2026, and a BETA release on February 27, 2026, containing selected acquisitions from October 17, 2025, through January 20, 2026. Consequently, June 17, 2026, is not the start of the entire public acquisition record. These are documented release/acquisition dates, not BailaSAR measurements.
The opened July notice supports the July 20, 2026, calibrated release and acquisitions on or after June 17, 2026: https://asf.alaska.edu/notices/nisar-l-band-data-now-publicly-available/ . Its broad first-release wording must be read alongside the release history's earlier BETA records.
The ASF release history and product overview support the November 6, 2026, VALIDATED release for Level 0 through Level 2, including GCOV/GUNW, for acquisitions starting October 21, 2026: https://nisar-docs.asf.alaska.edu/products-overview/ . This does not make earlier provisional earthquake-era acquisitions validated. Earthdata's alert index returned HTTP 403; the ASF documentation supplies the validated-release evidence.
