The public [SIGPER item](https://www.arcgis.com/home/item.html?id=900f6ace1d54413d8056494b749e25bf)
is owned by `sigper_arcgis`; its neighborhood layer returned polygon metadata
and a polygon in a one-record GeoJSON query. The city's
[portal announcement](https://www.pereira.gov.co/publicaciones/1442/propuesta-del-gobierno-de-la-ciudad-fue-elegida-en-convocatoria-mundial-del-programa-de-las-naciones-para-los-asentamientos-humanos-un-habitat-y-geo/)
supports the institutional portal attribution. Full boundary validity, adoption,
ID uniqueness, event-date vintage, and reuse terms remain unchecked.

The [council recovery update](https://concejopereira.gov.co/es/ieventos/ver/3052/concejo-de-pereira-analiza-avances-de-infraestructura-y-exige-resultados-concretos-en-la-atencion-de-la-emergencia-por-el-terremoto/)
dated 2026-11-11 is a damage-source lead, not a complete neighborhood label table.
No missing report was encoded as an undamaged unit. See the report for measured
service counts, query reproduction, and the current uninformative outcome.
