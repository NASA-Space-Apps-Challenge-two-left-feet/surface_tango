# Data licenses and attribution — proposal

Apache-2.0 is proposed for team-owned code (see [LICENSE](LICENSE)); the team decision is pending. Data and cache assets retain their own terms independently of the code license. The cache release must ship this file, with the applicable terms and attribution confirmed for its contents before redistribution. Agency names are attribution, not endorsement. No NASA logos.

This inventory follows the dataset table in `README.md` and the shared checkout's `local_cache/aburra/manifest.json`, `local_cache/eje_cafetero/manifest.json`, and `local_cache/mojana/manifest.json`. The FABDEM and MERIT Hydro terms below were checked against their publisher or developer pages on 2026-11-15; the other license entries remain **to confirm**. Notes for whoever confirms:

- Record the primary terms URL, exact product/version, required attribution, verification date and repository evidence (`file:line`) for each row. Confirm source terms as well as any GEE catalog/distribution conditions. Public availability alone does not establish redistribution permission.
- FABDEM V1-0's publisher states CC BY-NC-SA 4.0; the GEE listing uses that license for the asset used here. MERIT Hydro v1.0.1 is dual-licensed under CC BY-NC 4.0 or ODbL 1.0. **Inference for release review:** neither dataset's derived layers should inherit the proposed Apache-2.0 code license automatically. The team must choose the applicable MERIT option and confirm how the slope and HAND layers may be redistributed, plus their required notices, before publishing the cache.
- Check the reported OSM ODbL requirements, including attribution and share-alike for derived databases (**to confirm**). Distinguish derived databases from produced maps and document extract provenance and treatment of combined databases.
- Confirm the standard Sentinel credit wording, reported as “Contains modified Copernicus Sentinel data [year]”, and whether each output is modified; fill the year from its actual source scenes only after checking the terms.
- CHIRPS has a catalog reference at `docs/kb/chirps-daily-publication-lag.md:4`, but the note does not cite license terms. The inspected manifests record the rain source as `missing`; the collection ID above comes from the code and the user-supplied inventory, not an available rain layer.
- Preserve manifest granule/scene IDs, asset IDs, dates and derived-layer provenance alongside this file in the cache release. Inventory the actual release contents again, including map backgrounds or additional third-party assets; the dataset table does not grant rights to those assets.
- Do not apply the proposed code license to third-party data, dependency files, documentation or media by implication. Team-owned documentation/media licensing and third-party notices require their own scope decisions.
